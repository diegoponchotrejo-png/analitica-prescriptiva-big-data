# Dataset

El archivo `inventario.csv` es un dataset pequeño creado para demostrar el funcionamiento del proyecto.

## Columnas

- `producto`: nombre del producto.
- `stock_actual`: unidades disponibles actualmente.
- `ventas_ultimos_30_dias`: unidades vendidas en los últimos 30 días.
- `stock_minimo`: reserva mínima deseada.
- `tiempo_reposicion_dias`: días aproximados que tarda en llegar nuevo inventario.

El programa usa estos datos para calcular una demanda diaria aproximada, un punto de reorden y una recomendación de acción.
