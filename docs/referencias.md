## Inventarios y punto de reorden

Oracle NetSuite. **Inventory Optimization Calculations**.  
https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/article_0702045810.html

La documentación presenta el punto de reorden como:

```text
Reorder Point = Safety Stock + (Average Lead Time × Average Daily Demand)
```

Esta fórmula es la base de la utilizada en el proyecto.

Oracle Inventory. **Reorder Point Planning**.  
https://docs.oracle.com/cd/A60725_05/html/comnls/us/inv/roplan.htm

Describe el uso de demanda esperada durante el lead time y stock de seguridad para decidir cuándo realizar un nuevo pedido.
